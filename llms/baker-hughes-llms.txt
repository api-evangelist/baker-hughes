# Baker Hughes

> Baker Hughes is an energy technology company. Its digital portfolio is the Cordant industrial software platform (asset performance management, process optimization, emissions management) and the BHC3 AI Suite built with C3.ai. Cordant "offers APIs for integration" with enterprise and OT/IT systems, but no public API reference, OpenAPI, SDK or self-serve developer sign-up is published: the developer portal at developer.bakerhughes.com is a Backstage instance whose catalog is behind a Keycloak login.

Generated by API Evangelist on 2026-09-17 from the company's public web surface and the api-evangelist/baker-hughes profile. Baker Hughes does not publish an llms.txt of its own (www.bakerhughes.com/llms.txt answers an Imperva challenge; developer.bakerhughes.com/llms.txt answers the SPA shell).

## Products

- [Cordant](https://www.bakerhughes.com/cordant): Modular industrial software platform for APM, process optimization and emissions management.
- [Cordant platform](https://www.bakerhughes.com/cordant/platform): Platform overview; the only public page that mentions APIs and OT/IT connectivity.
- [Baker Hughes and C3.ai (BHC3 AI Suite)](https://www.bakerhughes.com/cordant/solutions/strategic-partnerships-and-alliances/c3ai): Enterprise AI applications for oil and gas, running on Microsoft Azure.

## Developer surface

- [Baker Hughes Developer Portal](https://developer.bakerhughes.com): Backstage developer portal. Anonymous access shows only a sign-in; the catalog API (/api/catalog/entities) returns 401 "Missing credentials". Support: cordant_success@bakerhughes.com.
- [OIDC discovery (Keycloak realm 'dedicated')](https://auth-developer.bakerhughes.com/auth/realms/dedicated/.well-known/openid-configuration): The one machine-readable document Baker Hughes serves for this surface — OpenID Connect / OAuth 2.0 metadata with PKCE, PAR, device, CIBA, token-exchange and mTLS support.
